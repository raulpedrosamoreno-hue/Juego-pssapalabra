# Rosco Deportivo

Juego de pasapalabra sobre deportes hecho con HTML, CSS y JavaScript puro.

## Cómo jugar
Abre `index.html` en el navegador. Responde a cada letra o pulsa **Pasa**. Tienes 3 minutos.

## Publicar en GitHub Pages
1. Sube estos archivos a un repositorio.
2. Ve a Settings → Pages → selecciona la rama `main` y la carpeta raíz.

## Estructura
- `index.html` – página
- `css/style.css` – estilos y animaciones
- `js/questions.js` – preguntas (edítalas aquí)
- `js/sounds.js` – sonidos con Web Audio
- `js/game.js` – lógica del juego
- `img/` – imágenes
